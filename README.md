# Operating System Navigation Efficiency

## How to Use (Mac/Window Task One)
Have a notes/notepad window with instructions open in full screen. Upon closing the notes/notepad window, a timer will start. Upon opening the settings, the timer will end, and the time will be stored in the respective task_one_results.csv in \OperatingSystemNavigationEfficiency\Data\

## Setup (Task One)

### Windows:
Load instructions to notepad. Run PowerShell as administrator 
PowerShell: Run this command in the folder
```bash
cd "(path to "Windows Scripts" folder)"
powershell -ExecutionPolicy Bypass -File .\WindowsTaskOne.ps1
```

### Mac: 
Load instructions to notes.
Compile and run in Script Editor.
